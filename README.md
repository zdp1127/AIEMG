# AIEMG: Active Learning Integrated with Molecular Generation

AIEMG is an MCTS-based (Monte Carlo Tree Search) molecular design framework that combines Pareto optimization with activity cliff detection and intrinsic-extrinsic reward mechanisms for de novo drug design.

## (i) Computational Environment

### Hardware Requirements
- **CPU**: Multi-core processor recommended for parallel docking
- **GPU**: NVIDIA GPU with CUDA 11.x support (optional, for faster training)
- **Memory**: 16GB RAM minimum, 32GB recommended

| Open Babel | 3.x | File format conversion |
| pygmo | 2.9 | Hypervolume calculation |
| NumPy | 1.21.x | Numerical computing |
| Pandas | 1.2.4 | Data manipulation |

## (ii) Installation and Setup

### Step 1: Create Environment
```bash
# Using conda
conda create -n AIEMG python=3.7
conda activate AIEMG

# Using virtualenv (alternative)
python3 -m venv aiemg_env
source aiemg_env/bin/activate
```

### Step 2: Install Python Dependencies
```bash
# Clone the repository
git clone https://github.com/your-repo/AIEMG.git
cd AIEMG

# Install core dependencies
pip install -r requirements.txt
```

### Step 3: Install RDKit (via conda, recommended)
```bash
conda install -c rdkit rdkit
```

### Step 4: Install TensorFlow with GPU Support (optional)
```bash
pip install tensorflow==2.9.1
# For GPU acceleration:
pip install tensorflow-gpu==2.9.1
```

### Step 5: Verify Installation
```bash
python -c "import rdkit; import tensorflow; import pygmo; print('All dependencies OK')"
```

## (iv) Dataset and Molecular Vocabulary

### ZINC250k Dataset
The pre-processed ZINC250k dataset is included at:
```
data/250k_rndm_zinc_drugs_clean.smi
```
This dataset contains ~250,000 drug-like molecules from the ZINC database.

### Molecular Vocabulary Construction
The vocabulary is automatically constructed from the ZINC dataset when training the RNN model. The vocabulary file is generated by `train_RNN/train_RNN.py` and includes:
- Atom symbols: C, N, O, S, F, Cl, Br, I, P
- Special tokens: `&` (start), `\n` (end)
- Ring notation: `1`, `c`, `n`, `s`, etc.
- Branching: `(`, `)`
- Bond types: `=`, `#`, `-`

The pretrained model weights are located at:

```
model/model_AIEMG.h5
```

The model is configured in `template_for_data/input/python_config.json`:
```json
{
    "whereisRNNmodelDir": "./model/",
    "rnnModelFile": "model_AIEMG.h5"
}
```

### Using the Model
The model is automatically loaded by the MCTS ligand design pipeline. No manual loading is required for standard usage.

### Training a New Model
To train from scratch:
```bash
python train_RNN/train_RNN.py
```

## (vi) Receptor Preparation

### Supported Receptors
The repository includes pre-prepared receptor files for:
- **EGFR** (Epidermal Growth Factor Receptor): `template_for_data/input/EGFR.pdbqt`
- **3PP0** (Example receptor): `template_for_data/input/3PP0.pdbqt`

### Preparing New Receptors
1. Download PDB structure from RCSB PDB
2. Prepare using AutoDock Tools or MGLTools:
   ```bash
   # Install MGLTools
   # Use ADT (AutoDock Tools) GUI to:
   # 1. Remove water molecules
   # 2. Add hydrogens
   # 3. Assign Gasteiger charges
   # 4. Save as .pdbqt format
   ```

3. Place the receptor file in `template_for_data/input/`

### Receptor Configuration Files
Grid box parameters are defined in:
- `template_for_data/input/EGFR_config.txt`
- `template_for_data/input/3PP0_config.txt`

Example configuration:
```
#binding_pocket
center_x = 21.857
center_y = 0.260
center_z = 52.761

size_x = 25
size_y = 25
size_z = 25
```

## (vii) Docking Parameters

### AutoDock Vina Configuration
The docking parameters are configured in `python_config.json`:

| Parameter | Default | Description |
|-----------|--------|-------------|
| exhaustiveness | 32 | Parallelization for docking |
| num_modes | 10 | Maximum binding modes |
| energy_range | 3.0 | Energy difference threshold |

### Grid Box Definitions

#### EGFR Receptor
```
Center: (21.857, 0.260, 52.761)
Size: (25, 25, 25) Angstroms
```

#### 3PP0 Receptor
```
Center: (configured in 3PP0_config.txt)
Size: (25, 25, 25) Angstroms
```

### Customizing Docking Parameters
Edit `template_for_data/input/python_config.json`:
```json
{
    "proteinName": "receptor",
    "vina_config": {
        "exhaustiveness": 32,
        "num_modes": 10,
        "energy_range": 3.0
    }
}
```

## (viii) Random Seeds

### Default Random Seed
### "randomSeed": 42,123,333,999
The default random seed is configured in `python_config.json`:
```json
{
    "randomSeed": 42
}
```

### Reproducibility
Setting the random seed ensures reproducibility of:
- MCTS tree expansion
- SMILES generation
- Hypervolume calculations
- Training (if retraining)

### Changing the Seed
To use a different seed, modify `python_config.json`:
```json
{
    "randomSeed": 123
}
```

Or pass via command line (if supported):
```bash
python ligand_design/mcts_ligand.py ./template_for_data/ --seed 123
```

## (ix) Usage

### Quick Start

#### 1. Generate Molecules with MCTS
```bash
# Activate environment
conda activate AIEMG

# Run MCTS molecular design
python ligand_design/mcts_ligand.py ./template_for_data/
```

#### 2. Train RNN Model (Optional)
```bash
python train_RNN/train_RNN.py
```

### Advanced Configuration
Edit `template_for_data/input/python_config.json`:
```json
{
    "isLoadTree": false,
    "whereisRNNmodelDir": "./model/",
    "rnnModelFile": "model_AIEMG.h5",
    "limitBudget": 84600,
    "max_docking_calls": 20000,
    "CostPerMolecule": 50,
    "randomSeed": 42,
    "saThreshold": 6,
    "enable_activity_cliff": true,
    "enable_ier": true
}
```

### Parameter Descriptions
| Parameter | Description | Default |
|-----------|-------------|---------|
| isLoadTree | Resume from saved tree | false |
| limitBudget | Time budget in seconds (alternative to max_docking_calls) | 84600 |
| max_docking_calls | Maximum Vina docking calls (alternative to limitBudget) | 20000 |
| CostPerMolecule | Cost per molecule evaluation | 50 |
| randomSeed | Random seed for reproducibility | 42 |
| saThreshold | SA score threshold (1-10) | 6 |
| enable_activity_cliff | Enable activity cliff detection | true |
| enable_ier | Enable IER mechanism | true |

### Example: Running with EGFR Target
1. Ensure `EGFR.pdbqt` is in `template_for_data/input/`
2. Ensure `EGFR_config.txt` defines the binding site
3. Run:
```bash
python ligand_design/mcts_ligand.py ./template_for_data/
```

## (x) Output Files

### Generated Output Directory
All outputs are stored in `template_for_data/present/`:

| File | Description |
|------|-------------|
| `pareto.json` | Pareto front data (molecules and scores) |
| `ligands.txt` | Valid generated SMILES |
| `scores.txt` | Raw scores for all molecules |
| `output.txt` | Pareto front evolution log |
| `metrics.csv` | Hypervolume and diversity metrics over time |
| `metrics.json` | Latest metrics snapshot |
| `ier_history.csv` | IER component history |
| `ier_history.json` | IER statistics |
| `activity_cliffs.json` | Detected activity cliff pairs |
| `depth.txt` | MCTS tree depth for each generation |

### Score Dimensions
The `scores.txt` file contains 5-dimensional scores:
1. **Docking Score**: Molecular docking affinity (normalized, higher is better)
2. **QED**: Quantitative estimate of drug-likeness
3. **IER**: Intrinsic-Extrinsic Reward (novelty + diversity)
4. **SA Score**: Synthetic accessibility (normalized)
5. **ACS**: Activity Cliff Score

### Interpreting Results

#### Pareto Front
Check `pareto.json` for non-dominated solutions:
```json
{
    "front": [[0.85, 0.72, 0.65, 0.80, 0.90], ...],
    "compounds": ["CCO...", "CCN...", ...]
}
```

#### Hypervolume Metrics
`metrics.csv` tracks:
- Number of generated molecules
- Hypervolume (Pareto quality)
- Diversity (Tanimoto distance)
- Efficiency (molecules/hour)

## (xi) Metrics Calculation

### Property Calculation Script
Calculate molecular properties for generated molecules:
```bash
python data/calc_props.py
```

This calculates:
- QED (drug-likeness)
- SA score (synthetic accessibility)
- LogP (lipophilicity)
- Molecular weight
- TPSA (topological polar surface area)
- HBD/HBA (hydrogen bond donors/acceptors)
- ESOL logS (water solubility)
- Permeability classification
- Toxicity alerts
- Docking scores

### Diversity Analysis
Calculate molecular diversity metrics (internal diversity and scaffold diversity):
```bash
python data/calc_props.py
```

This script calculates:
- **QED**: Drug-likeness (0-1, higher is better)
- **SA Score**: Synthetic accessibility (1-10, lower is easier to synthesize)
- **Internal Diversity**: Based on Morgan fingerprint Tanimoto distance (1 - avg_similarity)
- **Scaffold Diversity**: Unique Murcko scaffold ratio (unique_scaffolds / total)
- **Additional properties**: MW, LogP, HBA, HBD, TPSA, NumRings, RotatableBonds

Output:
- `template_for_data/present/ligands_props.csv`: CSV file with all properties
- Console: Statistics including internal diversity, scaffold diversity, QED/SA/MW distributions

**Configuration**: Edit `INPUT_FILE` and `OUTPUT_FILE` paths in `data/calc_props.py`

### IER Component Analysis
Visualize IER components over time:
```bash
python template_for_data/visualize_ier.py
```

### Correlation Analysis
Analyze correlations between score dimensions:
```bash
python template_for_data/analyze_scores_correlation.py
```

### H_max Sensitivity Analysis
Study the effect of history memory size:
```bash
python template_for_data/analyze_h_max_sensitivity.py --input template_for_data/present/ligands.txt --output template_for_data/analysis_results/
```
